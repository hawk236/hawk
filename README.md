# 🤍 吉伊 - 桌面宠物

一个可爱的桌面宠物应用，角色是chiikawa的吉伊。支持多种交互动作和表情。

## 🎨 角色特点

- **外观设计**：白色圆滚滚，头身连一体，两个小圆耳朵，四肢短小
- **风格**：极简、柔萌、可爱，就像软乎乎的小棉球
- **表情**：丰富的表情包式表现力，可爱又乖巧

## 🎭 支持的状态

1. **idle** - 正常站立，轻轻呼吸，偶尔眨眼
2. **happy** - 眯眼开心，挥小手，脸颊更红
3. **shy** - 低头害羞，身体左右摇晃，脸颊腮红明显
4. **cry** - 委屈哭泣，眼泪掉下来
5. **surprised** - 吓一跳，眼睛睁大，身体弹起
6. **clicked** - 点击后害羞开心，出现小爱心 ❤️
7. **drag** - 被拖动时两手举起，表情惊慌
8. **sleep** - 闭眼睡觉，轻轻上下浮动，旁边有 zzz
9. **study** - 坐着看书，表情认真可爱

## 🚀 安装和运行

### 环境要求
- Node.js 16+
- npm 或 yarn

### 安装依赖

```bash
npm install
```

这会安装 Electron 和其他必要的依赖。

### 运行应用

```bash
npm start
```

开发模式（带开发者工具）：

```bash
npm run dev
```

## 🎮 交互方式

- **单击**：触发随机反应（开心/害羞/惊吓/点击后反应）
- **拖动**：拖动宠物窗口位置
- **双击**：进入学习状态
- **放置不管**：宠物会自动进入各种自发动作（睡觉、学习、哭泣等）

## 📁 项目结构

```
hawk/
├── src/
│   ├── main.js              # Electron 主进程
│   ├── preload.js           # Electron 预加载脚本
│   ├── index.html           # 主 HTML 文件，包含 SVG 角色定义
│   ├── styles/
│   │   └── pet.css          # 样式和动画定义
│   └── assets/
│       ├── pet-renderer.js  # 渲染器和动画逻辑
│       └── pet-logic.js     # 宠物交互和状态管理
├── package.json
└── README.md
```

## 🎨 SVG 设计特点

- 使用纯 SVG 矢量图形，用粗黑色线条（stroke-width: 4）
- 身体是干净的奶白色（#f5f5f5）
- 黑色圆眼睛，带白色高光反射
- 浅粉色椭圆腮红
- 深粉色害羞线条
- 所有边缘干净清晰，无阴影和毛发纹理

## ⚙️ 自定义选项

可以在以下文件中调整参数：

- **窗口大小**：`src/main.js` 中的 `width` 和 `height`
- **颜色方案**：`src/index.html` 中的 SVG 属性
- **动画速度**：`src/styles/pet.css` 中的 animation-duration
- **行为逻辑**：`src/assets/pet-logic.js` 中的状态转换时间
